## The brief

Bon House is an Atlanta DIY residential music venue in Decatur, a 150-cap room with
a PBR sponsorship and an audience that keeps growing. It needed a web presence with
the same energy as the room, not another quiet minimal site.

## The build

The site runs on a distinct, energetic collage aesthetic: brush display type, a
torn-paper photo hero, and a grid that holds the venue's whole world, bands, the
room, the studio, and the label, in one place. Underneath it is a TypeScript and
Next.js build on a small design system, so events, listings, and new sections can be
added fast without the layout drifting, and the venue can keep it current without a
developer in the loop for every change.

## Why it belongs here

Next to the contractor and video-store studies, Bon House shows range: a completely
different aesthetic executed with the same system discipline. This is a client
engagement; screens and brand assets appear only where the agreements allow, so this
page describes the work pending that review.
